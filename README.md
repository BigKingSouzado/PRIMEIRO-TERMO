# PRIMEIRO-TERMO
Material de aprendizagem do primeiro termo do senai - LOPAL - SOP - ARI - LER - 


## 💻 LOPAL (Lógica de Programação e Algoritmos)
Desenvolvimento do pensamento computacional e resolução de problemas utilizando a linguagem Python.

### Conceitos Chave

Variáveis e Tipos de Dados: Armazenamento de informações em memória (`int`, `float`, `str`, `bool`).

Estruturas Condicionais: Tomada de decisão no código (`if`, `elif`, `else`).

Estruturas de Repetição: Loops para automação de tarefas (`while` e `for`).

Estruturas de Dados: Manipulação de coleções de dados (Listas, Tuplas e Dicionários).

Funções: Modularização de código através de blocos reutilizáveis (`def`).

---

## 💽 SOP (Sistemas Operacionais)
Compreensão do funcionamento, gerenciamento e interação com o hardware através dos sistemas operacionais (ênfase em Windows Client/Server e Linux).

### Conceitos Chave

Arquitetura do S.O.: Entendimento do Kernel, Shell e a divisão entre modo usuário e modo kernel.

Gerenciamento de Processos: Ciclo de vida de processos, threads, prioridades e escalonamento de CPU.

Gerenciamento de Memória: Memória RAM, paginação, segmentação e memória virtual (Swap).

Sistemas de Arquivos: Organização e permissões de arquivos (NTFS, ext4).

Interface de Linha de Comando (CLI): Operação do sistema via Prompt de Comando (CMD/PowerShell) e Terminal Linux (Bash).

---

## 🌐 ARI (Arquitetura de Redes de Computadores)
Estudo do design, implementação e funcionamento das redes de comunicação de dados locais e globais.

### Conceitos Chave
Modelos de Referência: Camadas dos modelos OSI (7 camadas) e TCP/IP (4 camadas).

Endereçamento Lógico: Estrutura de endereços IPv4, máscaras de rede, sub-redes e introdução ao IPv6.

Protocolos Fundamentais: Funcionamento do DHCP (atribuição IP), DNS (resolução de nomes) e HTTP/HTTPS.

Equipamentos de Interconexão: Papel de Switches (Camada 2) e Roteadores (Camada 3) na topologia.

Cabeamento Estruturado: Normas e boas práticas para instalação de meios físicos passivos.

---

## 📋 LER (Levantamento de Requisitos)
Técnicas de Engenharia de Requisitos para identificar, analisar e documentar as necessidades de um cliente de software ou infraestrutura.

### Conceitos Chave

Tipos de Requisitos: Diferenciação entre Requisitos Funcionais (o que o sistema faz) e Não-Funcionais (restrições, desempenho, segurança).

Técnicas de Elicitação: Métodos de coleta de dados (Entrevistas, Questionários, Brainstorming, Observação Direta).

Documentação (Especificação): Criação do Documento de Especificação de Requisitos de Software (SRS).

Validação e Gestão: Processo de homologação dos requisitos com as partes interessadas ("stakeholders") e controle de escopo.
